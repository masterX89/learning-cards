# P5R Learning Card: train accident talk

## 画像内テキスト

### 1
**混んでんの、それのせいか。多いな、最近…**  
こんでんの、それのせいか。おおいな、さいきん…

- **混んでんの**
  - 完整形：混んでいるの
  - 日常説明：人や物がたくさんあって、ぎゅうぎゅうになっている感じ。
  - 中文：很拥挤
  - Forvo: https://ja.forvo.com/word/混む

- **せい**
  - 日常説明：何か悪いことが起きた時に、「原因はこれだ」と言う時に使う言葉。
  - 中文：原因；都怪……
  - Forvo: https://ja.forvo.com/word/せい

### 2
**そういや先月に、大きな交通事故があったな。**  
そういやせんげつに、おおきなこうつうじこがあったな。

- **そういや**
  - 完整形：そういえば
  - 日常説明：話している途中で、急に何かを思い出した時に使う言い方。
  - 中文：这么说来；说起来
  - Forvo: https://ja.forvo.com/word/そういえば

- **交通事故（こうつうじこ）**
  - 日常説明：車や電車などで、ぶつかったり人がけがをしたりする事故。
  - 中文：交通事故
  - Forvo: https://ja.forvo.com/word/交通事故

### 3
**お前がこっち来る前の話。**  
おまえがこっちくるまえのはなし。

- **こっち**
  - 日常説明：自分がいる場所や、自分に近い場所を指す時に使う言い方。
  - 中文：这边
  - Forvo: https://ja.forvo.com/word/こっち

### 4
**…亡くなった子、15歳だったっけか。**  
…なくなったこ、じゅうごさいだったっけか。

- **亡くなる（なくなる）**
  - 日常説明：人が死んだことを、少しやわらかく言う時の言い方。
  - 中文：去世
  - Forvo: https://ja.forvo.com/word/亡くなる

- **だったっけか**
  - 完整形：だったっけ？
  - 日常説明：自分の記憶が合っているか、少し確認したい時に使う言い方。
  - 中文：是……来着？
  - Forvo: https://ja.forvo.com/word/だったっけ

### 5
**親御さん、さぞかし…**  
おやごさん、さぞかし…

- **親御さん（おやごさん）**
  - 日常説明：ほかの人のお父さんやお母さんを、丁寧に言う時の言い方。
  - 中文：父母；家长
  - Forvo: https://ja.forvo.com/word/親御さん

- **さぞかし**
  - 日常説明：「きっとすごくそうだろうな」と想像して言う時に使う言葉。
  - 中文：想必一定很……
  - Forvo: https://ja.forvo.com/word/さぞかし

## UI / 表示

- **昼間**  
  ひるま
  - 日常説明：朝でも夜でもなく、昼の時間のこと。
  - 中文：白天；中午前后
  - Forvo: https://ja.forvo.com/word/昼間

- **音声再生**  
  おんせいさいせい
  - 日常説明：録音された声や音をもう一度流すこと。
  - 中文：播放语音
  - Forvo: https://ja.forvo.com/word/音声再生
