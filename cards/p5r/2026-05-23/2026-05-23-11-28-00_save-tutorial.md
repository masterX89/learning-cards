# P5R Learning Card: save tutorial

## 画像内テキスト

### 1
**これまでの内容をセーブする**  
これまでのないようをせーぶする

- **これまで**
  - 日常説明：今まで、ここまでのことを言う時によく使う言葉。
  - 中文：至今为止
  - Forvo: https://ja.forvo.com/word/これまで

- **内容（ないよう）**
  - 日常説明：話やデータの中に入っているもの。
  - 中文：内容
  - Forvo: https://ja.forvo.com/word/内容

- **セーブ**
  - 日常説明：ゲームの進み具合を記録して、あとで続きから遊べるようにすること。
  - 中文：保存游戏
  - Forvo: https://ja.forvo.com/word/セーブ

### 2
**＋で現在のプレイの進捗をセーブすることができます。**  
ぷらすでげんざいのぷれいのしんちょくをせーぶすることができます。

- **現在（げんざい）**
  - 日常説明：今、この時のこと。
  - 中文：当前；现在
  - Forvo: https://ja.forvo.com/word/現在

- **プレイ**
  - 日常説明：ゲームを遊ぶこと。
  - 中文：游玩；游戏过程
  - Forvo: https://ja.forvo.com/word/プレイ

- **進捗（しんちょく）**
  - 日常説明：どれくらい進んでいるか、という状態。
  - 中文：进度
  - Forvo: https://ja.forvo.com/word/進捗

### 3
**画面左下に、図のようなヘルプ表示が出ている時ならいつでもセーブを行うことが可能です。**  
がめんひだりしたに、ずのようなへるぷひょうじがでているときならいつでもせーぶをおこなうことがかのうです。

- **画面（がめん）**
  - 日常説明：ゲームやパソコンなどに映っている映像のこと。
  - 中文：画面
  - Forvo: https://ja.forvo.com/word/画面

- **ヘルプ表示（へるぷひょうじ）**
  - 日常説明：操作方法などを教えてくれる説明の表示。
  - 中文：帮助提示
  - Forvo: https://ja.forvo.com/word/ヘルプ

- **〜時なら（ときなら）**
  - 日常説明：その条件の時だけ、という意味で使う言い方。
  - 中文：如果是在……的时候
  - Forvo: https://ja.forvo.com/word/時

- **行う（おこなう）**
  - 日常説明：何かを実際にする、という少しかたい言い方。
  - 中文：进行；执行
  - Forvo: https://ja.forvo.com/word/行う

- **可能（かのう）**
  - 日常説明：できる、という意味の少しかたい言葉。
  - 中文：可以；能够
  - Forvo: https://ja.forvo.com/word/可能
