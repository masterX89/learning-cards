# P5R Learning Card: 裏切りのエース

## 画像内テキスト

### 1
**陸上部のエースも堕ちたものよ。**  
りくじょうぶ の エース も おちた もの よ。

- **エース**
  - 日常説明：チームの中で一番活躍する人。
  - 中文：王牌主力。
  - Forvo: https://ja.forvo.com/word/エース

- **堕ちたものよ（おちたものよ）**
  - 日常説明：昔よりひどくなったことを見下して言う表現。
  - 中文：真是堕落了啊。

### 2
**あぁ!? 何が言いてえ!?**  
ああ！？ なに が いいてえ！？

- **言いてえ**
  - 完整形：言いたい
  - 日常説明：言いたい、の乱暴な言い方。
  - 中文：想说什么。

### 3
**暴力騒ぎを起こして、仲間の夢を潰した『裏切りのエース』君。**  
ぼうりょくさわぎ を おこして、なかま の ゆめ を つぶした「うらぎり の エース」くん。

- **暴力騒ぎ（ぼうりょくさわぎ）**
  - 日常説明：暴力に関するトラブルや事件。
  - 中文：暴力事件。
  - Forvo: https://ja.forvo.com/word/暴力騒ぎ

- **潰す（つぶす）**
  - 日常説明：希望や計画をだめにすること。
  - 中文：毁掉、断送。
  - Forvo: https://ja.forvo.com/word/潰す

- **裏切り（うらぎり）**
  - 日常説明：信頼していた人を裏切ること。
  - 中文：背叛。
  - Forvo: https://ja.forvo.com/word/裏切り

### 4
**貴様の自分勝手の巻き添えになった連中が、いやはや…可哀想で仕方ない。**  
きさま の じぶんかって の まきぞえ に なった れんちゅう が、いやはや……かわいそう で しかたない。

- **自分勝手（じぶんかって）**
  - 日常説明：自分のことだけを考えて行動すること。
  - 中文：自私任性。
  - Forvo: https://ja.forvo.com/word/自分勝手

- **巻き添え（まきぞえ）**
  - 日常説明：他人の問題に関係なく巻き込まれて被害を受けること。
  - 中文：受牵连、遭池鱼之殃。
  - Forvo: https://ja.forvo.com/word/巻き添え

- **連中（れんちゅう）**
  - 日常説明：人たちを少し乱暴に言う表現。
  - 中文：那帮人。
  - Forvo: https://ja.forvo.com/word/連中

- **いやはや**
  - 日常説明：驚きやあきれを表す言葉。
  - 中文：哎呀呀；真是。

- **可哀想で仕方ない（かわいそうでしかたない）**
  - 日常説明：とても気の毒だと思うこと。
  - 中文：实在太可怜了。

## 中文概要

鴨志田は竜司を「裏切りのエース」と呼び、暴力事件によって仲間の夢を潰した張本人だと責める。さらに、竜司の自分勝手な行動のせいで周囲の部員が巻き添えになったと非難し、皮肉を込めて「可哀想で仕方ない」と言い放つ。
