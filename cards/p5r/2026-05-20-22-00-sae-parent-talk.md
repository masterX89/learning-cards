# P5R Learning Card — Sae / Parent Talk

## セリフ

### どうせ誰も親身に構っちゃくれないのに。
どうせだれもしんみにかまっちゃくれないのに。

- 親身（しんみ）
  - 相手のことを本気で考えて、やさしく接すること
  - 真心关心、设身处地

- 構う（かまう）
  - 気にする、相手を世話する
  - 在意、照顾、关心

- 構っちゃくれない
  - 構ってはくれない
  - 很口语的缩略说法
  - 根本不关心我

### …学校であの調子じゃ、この先、俺もなんか言われちまうかも知れねぇな…
…がっこうであのちょうしじゃ、このさき、おれもなんかいわれちまうかもしれねぇな…

- 調子（ちょうし）
  - 様子、状態
  - 状态、样子

- この先（このさき）
  - これから先、未来
  - 今后、之后

- 言われちまう
  - 言われてしまう
  - 「〜てしまう」的口语缩略
  - 被别人说闲话、被指责

- かもしれねぇ
  - かもしれない
  - 男性粗口语说法

Forvo:
https://ja.forvo.com/word/調子/

### メンドくせえの、預かっちまったぜ…
めんどくせえの、あずかっちまったぜ…

- メンドくせえ
  - 面倒くさい
  - 非常口语、粗鲁男性说法
  - 麻烦死了

- 預かる（あずかる）
  - 一時的に人や物を受け取って管理する
  - 暂时照看、接收

- 預かっちまった
  - 預かってしまった
  - 不小心接下了

Forvo:
https://ja.forvo.com/word/預かる/

### …なぜ引き取った？
…なぜひきとった？

- 引き取る（ひきとる）
  - 人を自分のところへ受け入れる
  - 收留、接走

Forvo:
https://ja.forvo.com/word/引き取る/

---

### 頼まれて…なんとなく、覚悟しちまったんだよな…
たのまれて…なんとなく、かくごしちまったんだよな…

- 頼まれて（たのまれて）
  - 頼まれる → 被拜托

- なんとなく
  - はっきりした理由はないが、自然に
  - 不知为何、总觉得

- 覚悟（かくご）
  - 大変なことを受け入れる気持ち
  - 做好心理准备、觉悟

- 覚悟しちまった
  - 覚悟してしまった
  - 不知不觉做好觉悟了

Forvo:
https://ja.forvo.com/word/覚悟/
