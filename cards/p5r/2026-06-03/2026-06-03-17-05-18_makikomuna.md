# P5R Learning Card: 巻き込むなよ

## 画像内テキスト

### 1
**俺、嫌なんだよ、お前達みたいに睨まれんのさ…**  
おれ、いや なんだ よ、おまえたち みたい に にらまれん の さ……

- **嫌（いや）**
  - 日常説明：したくない、好きではない気持ち。
  - 中文：讨厌；不愿意。
  - Forvo: https://ja.forvo.com/word/嫌

- **睨む（にらむ）**
  - 日常説明：怒った顔や強い目つきで相手を見ること。
  - 中文：瞪；怒视。
  - Forvo: https://ja.forvo.com/word/睨む

- **睨まれん**
  - 完整形：睨まれる
  - 日常説明：人から怖い目つきで見られること。
  - 中文：被瞪；被怒视。

### 2
**だから巻き込むなよ…**  
だから まきこむ な よ……

- **巻き込む（まきこむ）**
  - 日常説明：関係ない人まで問題や事件に入れてしまうこと。
  - 中文：卷入；牵连。
  - Forvo: https://ja.forvo.com/word/巻き込む

- **巻き込むな**
  - 完整形：巻き込むな
  - 日常説明：自分をその問題に入れるな、という命令。
  - 中文：别把我卷进去。

## UI / 表示

- **目の死んだバレー部員**  
  め の しんだ バレーぶいん

- **目の死んだ**
  - 日常説明：希望や元気がなく、生気のない目の様子。
  - 中文：眼神死了；毫无生气。

- **バレー部員**
  - バレーボール (volleyball)
  - 日常説明：バレー部に所属している学生。
  - 中文：排球部成员。
  - Forvo: https://ja.forvo.com/word/バレー部員

## 重要表現

### 睨まれる

- 先生に睨まれる
  - せんせい に にらまれる
  - 被老师瞪。

- 上司に睨まれる
  - じょうし に にらまれる
  - 被上司盯上。

### 巻き込む

- 友達を巻き込む
  - ともだち を まきこむ
  - 把朋友卷进去。

- 事故に巻き込まれる
  - じこ に まきこまれる
  - 被卷入事故。

## 中文概要

被关押的排球部学生已经失去了反抗的意志。他表示自己不想像主角等人一样被监视和针对，因此希望不要把自己卷入这件事之中。
